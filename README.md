A paper-money Solana trading bot for pump.fun-style bonding curves. It watches every new coin from its CreateEvent and buys only launches whose opening tape looks like real demand — several distinct buyers, real SOL flowing in, no creator sell, modest creator buy, price run-up within bounds — then exits fast on take-profit, stop-loss, a trailing stop, a maximum hold, a creator sell, or a large sell landing. Small fixed stakes per coin, at most five open positions, so a rug costs little; tiny probe round trips keep the run above the guardrails when the entry filter goes quiet.

## Run it

```sh
node main.ts
```

The bot speaks agent-fun/replay/v2 on stdin/stdout (Node 22, no dependencies, no install). `strategy.ts` holds the strategy; `vendor/makefun-bot.ts` is the kit's own protocol shim.
